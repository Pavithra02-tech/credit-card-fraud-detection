# Credit Card Fraud Detection Using Machine Learning

## 📌 Overview

A machine learning project for detecting fraudulent credit card transactions. The project focuses on data preprocessing, exploratory data analysis, handling class imbalance, and comparing multiple classification algorithms.

## 🎯 Objective

To identify potentially fraudulent transactions using machine learning while addressing the challenges of highly imbalanced transaction data.

## 🛠️ Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* XGBoost
* Matplotlib
* Seaborn
* SMOTE
* Google Colab

## 🤖 Models Used

* Logistic Regression
* Decision Tree
* XGBoost
* Voting Classifier

## 🔄 Workflow

```text
Data Collection
      ↓
Data Cleaning & Preprocessing
      ↓
Exploratory Data Analysis
      ↓
Train-Test Split
      ↓
Feature Scaling
      ↓
SMOTE
      ↓
Model Training
      ↓
Model Evaluation
```

## 📊 Dataset

The project uses a publicly available credit card transaction dataset obtained from Kaggle.

The dataset is not included in this repository.
